# ModeSelectPage

**Path:** `src/pages/ModeSelectPage.tsx`
**Route:** `/flashcards/:deckType/:categoryId` (authenticated, inside [AppLayout](./AppLayout.md))

**Purpose:** Sits between picking a category ([SelectDeckCard](./SelectDeckCard.md) or [MyDecksPage](./MyDecksPage.md)) and actually playing — lets the user choose "Practice" or "10 Cards" for the category/deck they just picked.

**Props:** None — reads `deckType` and `categoryId` from the URL via `useParams`, and the selected subcategory (if any) from `useSearchParams`'s `subcategory` key (`null` means "All"). `deckType` (`'standard' | 'custom'`, see [useRandomFlashcard](../hooks/useRandomFlashcard.md)'s `DeckType`) is validated the same way as on [FlashcardPage](./FlashcardPage.md)/[TenCardsPage](./TenCardsPage.md) (`deckType === 'standard' || deckType === 'custom'`), falling into the "No category selected" error state otherwise — an unrecognized value in the URL is rejected here rather than silently passed through to default to `'standard'` further down.

**Key behavior:** Each mode renders as a `ModeTile` — an icon in a brand-muted circle, a label, and a one-line subtitle, stacked in a bordered tile — rather than a plain text button, because "Practice" and "10 Cards" alone gave no sense of what either mode actually does: `ModeTile` pairs `Infinity`/"Practice"/"Untimed, keep going" with navigation to `/flashcards/:deckType/:categoryId/practice` ([FlashcardPage](./FlashcardPage.md)), and `ListOrdered`/"10 Cards"/"Timed round, scored" with `/flashcards/:deckType/:categoryId/ten-cards` ([TenCardsPage](./TenCardsPage.md)). Both targets append `?subcategory=<id>` when a subcategory is selected, and omit the query string entirely for "All" — [FlashcardPage](./FlashcardPage.md) and [TenCardsPage](./TenCardsPage.md) both read it back out the same way.

The tile's accessible name is set explicitly via `aria-label={label}` on the `<button>`, and all three inner spans (icon, label, subtitle) are `aria-hidden="true"`. Without that, the subtitle's text would get folded into the button's accessible name automatically (it's inside the button), announcing label and subtitle as one run-on string — `aria-hidden` on the inner content plus an explicit `aria-label` keeps the accessible name to just the label.

Calls [useCategoryInfo](../hooks/useCategoryInfo.md) for the masthead's category name and its `isVocabulary` flag. The whole masthead is the `CardHeader` (`.selection-band`, the brand-tinted gradient, closed by a single `border-b border-brand`), and holds the category kicker followed, when `isVocabulary` is `true`, by [SubCategoryChips](./SubCategoryChips.md) as a direct sibling with no wrapper or divider between them. The chips sit in the same banded header rather than in a separate panel below it so the category and its topic chips read as one grouped "what you're selecting" unit, with one border closing it off before "Choose a mode". `CardHeader` overrides shadcn's default `gap-1` with `gap-4` to space the kicker row from the chip row. Non-vocabulary categories and custom decks render only the kicker. `CardContent` holds only the "Choose a mode" title and `.mode-select-grid`. Selecting a chip calls `setSearchParams` (`{ replace: true }`, so narrowing by topic doesn't pile up history entries) rather than local state — the selection travels as a URL query param so it survives back-navigation/refresh, the same reasoning [FlashcardPage](./FlashcardPage.md)/[TenCardsPage](./TenCardsPage.md) already relied on for `deckType`/`categoryId`.

The outer `Card` reuses [SelectDeckCard](./SelectDeckCard.md)'s `select-deck-card` class, and the page wraps its content in the same centering layout (`mx-auto flex max-w-4xl flex-col gap-6 p-4`) as [HomePage](./HomePage.md). The tile grid and tile styling live in `ModeSelectPage.css` (`.mode-select-grid`, `.mode-tile`, `.mode-tile-icon`, `.mode-tile-label`, `.mode-tile-subtitle`) rather than reusing `select-deck-button` — a `ModeTile` needs room for icon + label + subtitle, which the plain deck-button class doesn't lay out. `.mode-tile` hover/focus state darkens its bottom border and tints its text to `--brand`, and swaps `.mode-tile-icon` from `bg-brand-muted`/`text-brand` to `bg-brand`/`text-brand-foreground` — the same icon-chip treatment used elsewhere (e.g. [DeckGrid](./DeckGrid.md)'s `icon` prop).

**Depends on:** [useCategoryInfo](../hooks/useCategoryInfo.md), [SubCategoryChips](./SubCategoryChips.md), `Card`/`CardContent`/`CardHeader`/`CardTitle` from `src/components/ui/`, `lucide-react` (`Infinity`, `ListOrdered`, `Tag`), `useNavigate`/`useParams`/`useSearchParams` from `react-router-dom`, `src/components/SelectDeckCard.css`, `src/pages/ModeSelectPage.css`.

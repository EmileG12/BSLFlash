# utils

**Path:** `src/lib/utils.ts`
**Signature:** `export { cn } from "cn"`

**Purpose:** Re-exports `cn` from the `cn` npm package, a class-name merging helper for Tailwind CSS (a drop-in replacement for `clsx` + `tailwind-merge`). The shadcn-originated UI kit under `src/components/ui/` and several app components import `cn` from this path.

**Used by:** the `src/components/ui/*` kit, plus [LabeledInput](../components/LabeledInput.md), [TableCard](../components/TableCard.md), [TagChipList](../components/TagChipList.md), [SubCategoryChips](../components/SubCategoryChips.md), [EditDeckModal](../components/EditDeckModal.md), and the [BrowseDecksPage](../components/BrowseDecksPage.md), [SuperadminCategoriesPage](../components/SuperadminCategoriesPage.md), and [SuperadminWordEditPage](../components/SuperadminWordEditPage.md) pages.
